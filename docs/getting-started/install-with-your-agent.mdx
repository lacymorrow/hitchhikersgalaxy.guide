# Install with your coding agent

Paste this into Claude Code, Cursor, Codex or any coding agent. It reads the [install spec](https://github.com/shipkit-io/bones/blob/main/docs/agents/install.md) in Bones, asks you five questions, shows you the commands, and runs them after you say yes.

```text
Install ShipKit for me.

Read https://raw.githubusercontent.com/shipkit-io/bones/main/docs/agents/install.md and follow it exactly. If a step is not in that file, do not do it.

Ask me the five questions from the file one at a time, with the recommended answer first. If I say "defaults", skip straight to the plan. Show me the exact commands before you run anything and wait for my yes. Do not ask me to paste secrets into this chat: shadcn writes empty keys to .env.local, and you tell me where each value comes from. Touch only .env.local, the "shipkit" block in package.json, and files the CLI or shadcn created. When it is done, run the verify step and show me which features are on.
```

Both links pre-fill the prompt and wait for you to press Enter. Nothing runs until you do.

## What happens

1. The agent asks about your app's name, auth, payments, content and services. Say "defaults" for Neon Postgres, Better Auth with GitHub and Google, MDX content, Resend and no payments yet.
2. It creates the project from [Bones](https://github.com/shipkit-io/bones) with `npm create shipkit-app@latest` and adds the integrations you chose from the [ShipKit registry](/docs/features/registry) with `npx shadcn add @shipkit/<item>`.
3. Every env key the integrations need lands in `.env.local` empty. The agent prints where each value comes from; you fill them in.
4. It runs typecheck and the dev server and reports which features are on.

## Why a prompt and not an installer

The spec lives in the repo, next to the code, so it changes when the code changes. The prompt above never has to. Everything the agent does is a command you could run yourself; the agent only asks the questions and keeps the order straight.

If you would rather not use an agent, the [quick start](/docs/getting-started) has the same steps by hand.
