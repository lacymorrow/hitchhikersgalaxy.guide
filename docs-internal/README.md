# Internal docs

Planning notes, implementation checklists, and content calendars that are **not
published**.

Anything under `docs/` is rendered as public documentation by both providers
(see `src/config/docs-provider.ts`), so working notes live here instead. This
directory is deliberately outside the fumadocs collection root and outside
Holocron's `pagesDir`.

Put customer-facing documentation in `docs/`; put everything else here.
