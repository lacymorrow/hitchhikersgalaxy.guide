## How to execute a plan

1. Read the plan top-to-bottom before touching code.
2. Run the **Drift check** command at the top — abort if files have moved.
3. Work through **Steps** in order; do not skip the verification commands.
4. If any **STOP condition** triggers, stop and write a note on the issue.
5. When the plan is done, flip its Status cell to ✅ done and reference the
   merge commit / PR.

## Test-first ordering

Per the project owner's 2026-06-23 direction, do not start the P1 security
fixes (001-005) until the characterization-test plans (008, 009) are landed.
Those plans pin the current behavior of `payment-service` and `auth-service`
so the behavioral fixes that follow have a safety net.
